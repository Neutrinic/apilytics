### Changed

- **Pull requests add a changelog fragment, `changelog.d/<issue>.md`, instead of editing
  `CHANGELOG.md`.** Every pull request used to edit the same section, so each merge
  conflicted with every other open one. `.github/scripts/release_changelog.py` checks the
  fragments in CI and folds them into a release section. A new push to a pull request now
  cancels the CI run it replaces (#304).
