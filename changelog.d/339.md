### Changed

- **The image's `latest` tag now means the newest release.** Every push to main used to retag
  `latest`, so the quick start could pull unreleased code. Only release tags move it now (#339).

### Added

- **Development builds of main.** Each push to main publishes its jar to a `dev` pre-release on
  GitHub and its image as `ghcr.io/neutrinic/apilytics:dev`, for trying unreleased changes. They
  aren't releases and nothing goes to Maven Central (#339).
