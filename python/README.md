# apilytics (Python)

Placeholder for the Python bindings of [apilytics](https://github.com/Neutrinic/apilytics) —
a connector that turns APIs into queryable tables.

**Not yet implemented.** The project currently ships as:

- a Spark connector on Maven Central (`io.github.neutrinic:apilytics-spark-4-2_2.13`)
- a Docker image (`ghcr.io/neutrinic/apilytics`)

Python support is planned. Follow the repository for progress.
